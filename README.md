# 旧号码沿革核对

面向翻查多年纸质电话本、想重新联系老同事或老邻居的中老年人：把电话本上的旧号码，按自己录入的改号规则（区号拆分、号码升位、局号调整等）一步步推到今天，并核对试拨结果。

## 运行

```bash
npm install
npm run dev
```

浏览器打开终端里提示的地址（默认 http://localhost:5173）。

其他命令：`npm run typecheck`（类型检查）、`npm run build`（生产构建）。

## 功能与约定

- **原记录**：照电话本原样抄写号码，可填记录年代范围、当时地区、分机写法、页边批注，并可拍原页照片。照片、联系人、核对进度全部只存在本浏览器的 IndexedDB，不上传、不联网。
- **改号规则**：含生效区间、适用地区、旧前缀、替换段、变更后总位数；可修改、删除。
- **沿革链**：按时间先后套用规则。日期跨越规则、规则重叠、批注（地区/年代）缺位时，保留全部相容候选；绝不凭空补数字，尤其不把缺失区号补成当前所在地。
- **数字连线图**：每个候选可用 SVG 连线查看每一位数字的保留、插入、替换、删去；点选候选可回看原页依据（照片、批注）。
- **试拨标记**：接通 / 停号 / 空号 / 未确认；同一号码结果矛盾或同一记录两个候选都接通时，会定位到分歧规则；误标可撤销（已撤销区可恢复）。
- **规则改动即失效**：规则每次修改版本号 +1，相关候选立即重新推算，旧试拨标记移入「已失效的标记」；刷新页面后可继续核对。
- **联系卡打印**：只含原记录、候选号码和询问要点，并声明号码为推算候选、不代表仍属于原联系人。

## 技术栈

Vue 3 · TypeScript · Vite · SVG · IndexedDB（无后端，无网络请求）

首次打开会载入一组名称带「示例」的数据便于熟悉操作，可在「原记录」页一键清除。
